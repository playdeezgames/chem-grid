# Chem-Grid

Place atoms on an 8x8 grid, match every bond, close molecules for points, and keep the helium from filling the board. Endless mode with online top scores, and twenty puzzle levels.

Play: https://playdeezgames.github.io/chem-grid/ (GitHub Pages, built into `docs/` by `tools/pages.sh`) · itch.io: https://thegrumpygamedev.itch.io/chem-grid

Made with Odin compiled to WebAssembly. Code, pixel art (made with the Anvil of SPLORR!!) and sound were made by an AI agent (Claude Code) at TheGrumpyGameDev's direction. Font DINOBYTE by mby (CC BY 4.0, `assets/font/dbyte-LICENSE.txt`). Online scores use LootLocker; the key in `web/index.html` is LootLocker's public game key.
